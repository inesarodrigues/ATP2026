## Resumo
Neste trabalho foi nos pedido para fazer uma aplicação para manipulação de listas de inteiros com um menu que guarda uma lista de números inteiros e permite criá-la (aleatória ou escrita pelo utilizador), calcular soma, média, maior e menor, verificar se está ordenada e procurar um elemento. Termina com a opção 0, mostrando a lista guardada.
