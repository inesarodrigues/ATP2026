## Resumo
Neste trabalho foi nos pedido para fazer uma aplicação para gestão de alunos, em python, com menu que gere uma turma (lista de alunos, cada um com nome, id e três notas). Permite criar a turma, inserir e listar alunos, consultar por id, guardar/carregar de ficheiro e sair, voltando ao menu após cada operação. No fim, usa-se a aplicação para criar uma turma com 5 alunos.
